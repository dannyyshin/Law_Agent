# 🏛️ Law Agent: 개인 맞춤형 AI 법률 보조 시스템
**Product Specification & User Manual**

> [!NOTE]
> 본 문서는 법률 지식이나 개발 지식이 없는 일반 사용자가 **Law Agent**의 가치를 이해하고, 손쉽게 세팅하여 활용할 수 있도록 기획자의 시선에서 작성된 종합 안내서입니다.

---

## 1. Law Agent란 무엇인가요? (Product Vision)
**Law Agent**는 나만의 개인 파일(드롭박스)과 대한민국 법제처의 실시간 법령 데이터를 동시에 교차 검증하여, **절대 거짓말(할루시네이션)을 하지 않는 나만의 수석 변호사**입니다. 

기존의 챗GPT나 AI들은 법률 질문을 하면 "그럴싸한 가짜 법"을 지어내는 치명적인 문제가 있었습니다. 하지만 Law Agent는 철저하게 **[내가 업로드한 증거 자료]** 와 **[실제 대한민국 현행법]** 만을 바탕으로 IRAC(쟁점-규칙-적용-결론) 방식의 전문적인 법리 분석을 제공합니다.

---

## 2. 어떻게 작동하나요? (구현 원리)
Law Agent의 핵심은 **'멀티 에이전트(Multi-Agent)'** 시스템입니다. 사용자 눈에는 하나의 채팅창으로 보이지만, 보이지 않는 뒤편에서는 3명의 가상 AI 전문가가 역할을 분담하여 치열하게 회의를 진행합니다.

1. 🕵️‍♂️ **리서처 에이전트 (자료 조사관)**
   - 사용자가 질문을 던지면 가장 먼저 출동합니다.
   - MCP(Model Context Protocol)라는 혁신적인 기술을 통해 대한민국 법제처 시스템에 직접 접속하여, 질문과 관련된 **100% 최신 현행법과 판례**를 실시간으로 긁어옵니다.
2. 👨‍⚖️ **수석 변호사 에이전트 (분석가)**
   - 리서처가 가져온 [실제 법령]과 사용자의 드롭박스에 있는 [사건 PDF 파일들], 그리고 채팅창에 첨부된 [캡처 이미지]를 모두 종합합니다.
   - 이 세 가지 정보를 엮어 논리적인 법률 검토 보고서 초안(IRAC 구조)을 작성합니다.
3. ⚖️ **QA 판사 에이전트 (최종 검수자)**
   - 수석 변호사가 쓴 초안에 과장되거나 지어낸 내용이 없는지 마지막으로 팩트체크를 진행합니다.
   - 검증이 완료되면, 사용자가 이해하기 쉬운 최종 답변으로 다듬어 화면에 출력합니다.

---

## 3. 주요 기술적 특징 (Tech Summary)
- **클라우드 실시간 마운트 (Dropbox API)**: 매번 번거롭게 파일을 업로드할 필요 없이, 평소 쓰는 드롭박스 폴더에 사건별로 PDF를 넣어두기만 하면 AI가 실시간으로 문서를 읽고 인식합니다.
- **법률 MCP (Korean-Law-MCP)**: AI가 외부 세계(법제처 오픈 API)와 소통할 수 있게 해주는 최신 플러그인 기술입니다. 이를 통해 AI는 어제 개정된 법률까지 즉각적으로 파악할 수 있습니다.
- **멀티모달 시각 분석 (Gemini 3.5 Flash)**: 채팅창의 `+` 버튼을 통해 카카오톡 대화 캡처, 근로계약서 사진 등을 올리면, 텍스트뿐만 아니라 이미지 속 상황까지 완벽하게 인지하여 증거로 채택합니다.
- **건축학적 미니멀리즘 UI**: 구글 랩스의 프리미엄 다크 테마(Warm Limestone & Boston Clay)를 적용하여 모바일과 PC 어디서든 앱 설치 없이 고급스러운 사용자 경험을 제공합니다.

---

## 4. 일반인용 설치 및 셋팅 가이드 (No-Code)
개발 지식이 없어도, 클릭 몇 번으로 나만의 Law Agent를 소유할 수 있습니다.

### Step 1. 준비물 챙기기 (3가지 키 발급)
시스템을 움직이게 할 3가지 무료 '열쇠(Key)'를 준비합니다.
1. **[구글 제미나이 API 키]**: 구글 AI 스튜디오에 로그인하여 무료 API 키를 발급받습니다. (AI의 두뇌 역할)
2. **[드롭박스 Access Token]**: 드롭박스 개발자 콘솔에서 `앱 만들기`를 누른 후 발급받는 긴 영문/숫자 조합의 비밀번호입니다. (나의 문서고 출입증)
3. **[법제처 오픈 API 키]**: 공공데이터포털(또는 법제처)에서 법령 검색 API 이용 신청을 하여 발급받습니다.

### Step 2. 드롭박스 폴더 세팅
내 드롭박스 최상단에 사건별로 폴더를 만듭니다.
- 예: `1. 직장내괴롭힘_신고건`, `2. 전세금반환소송`
- 그리고 해당 폴더 안에 관련 PDF 증거물이나 계약서들을 그냥 넣어두기만 하시면 됩니다.

### Step 3. Streamlit Cloud에 앱 배포하기 (무료/1분 소요)
1. **[Streamlit Community Cloud](https://share.streamlit.io/)** 에 가입 및 로그인합니다.
2. `New App` 버튼을 누르고, 제공받으신 Law Agent 깃허브(GitHub) 저장소 주소를 연결합니다.
3. **가장 중요한 설정(Secrets)**: 앱 세팅의 `Advanced Settings` -> `Secrets` 창에 들어가서 Step 1에서 받은 열쇠들을 다음과 같이 입력합니다.
   ```toml
   GEMINI_API_KEY = "내_제미나이_키"
   DROPBOX_ACCESS_TOKEN = "내_드롭박스_토큰"
   KOREAN_LAW_OPEN_API_KEY = "내_법제처_키"
   LOGIN_PASSWORD = "내가_사용할_앱_비밀번호(예: 1234)"
   ```
4. `Deploy` 버튼을 누르면 끝입니다!

### Step 4. 모바일/PC에서 접속하기
- 배포가 완료되면 부여받은 나만의 고유 웹 링크(예: `https://my-law-agent.streamlit.app`)가 생성됩니다.
- 스마트폰 브라우저나 PC에서 이 링크로 접속하고, 내가 설정한 비밀번호(`1234`)를 치면 나만의 전속 AI 변호사 사무실이 열립니다!
