# Law Agent (v1.0) 복구 및 재시작 프롬프트 가이드

이 백업 파일을 추후 새로운 PC나 다른 환경에서 다시 활성화하고 싶을 때,
AI 어시스턴트(안티그래비티)에게 아래의 프롬프트를 그대로 복사해서 붙여넣으시면 완벽하게 복구할 수 있습니다.

==================================================
[👇 복구 요청 프롬프트 복사/붙여넣기]

안티그래비티, 내가 제공한 'Law_Agent_v1.0_Backup.zip' 파일의 압축을 풀고 기존 Law Agent v1.0 환경을 완벽하게 복구해서 다시 실행시켜 줘.

다음 절차를 반드시 순서대로 진행해:
1. 패키지 의존성 확인: 파이썬 가상환경에 필요한 패키지들(streamlit, google-generativeai, pymupdf, mcp, pypiwin32)이 모두 설치되어 있는지 점검하고, 누락된 게 있다면 설치해 줘.
2. 환경 변수 세팅: 앱을 실행하기 위해 필요한 `.env` 파일과 `GEMINI_API_KEY` 설정이 제대로 되어 있는지 확인해 줘.
3. 서버 재실행: `streamlit run app.py` 명령어를 사용해서 백그라운드 서버를 가동해 줘.
4. 레이아웃 검증: UI 레이아웃이 v1.0 상태(우측 툴바 숨김, 좌측 햄버거 메뉴 정상 작동, 대화 초기화 버튼 하단 고정)를 유지하는지 점검해 줘.
5. 바로가기 생성: 바탕화면에 'Law_Agent_실행하기.bat' 파일을 다시 생성해서 내가 언제든 편하게 켤 수 있게 만들어 줘.
==================================================

- 버전 정보: v1.0 (UI/UX 레이아웃 안정화, 햄버거 메뉴 복구, 대화 초기화 기능 적용 완료 버전)
- 주요 기능: 제미나이 3.5 플래시 통신, MCP 서버 네이티브 연동, 문서(PDF) 분석, 대화 초기화, 법률 상담 UI 최적화
